# DiPlay CN

> 个人自用修改版，仅供自己车上使用。

## 来源

基于 [serein-morii/DiPlay-CN](https://github.com/serein-morii/DiPlay-CN) 修改，其上游为官方 DiPlay `v0.2.22`。当前版本 `1.0.4-cn.1`，包名 `com.diplay.song`。

## 适用车型

- 车型：比亚迪 宋 Plus DM-i
- 车机：DiLink 3.0（Android 7.1 / API 25 及以上）

## 说明

- **纯个人使用**。在原版基础上按个人喜好调整了应用的默认值和部分功能，不是通用发行版，也没有针对其他车型做适配。
- 不同车型、不同车机固件的表现没有保证，**不建议其他车型使用**，也不处理其他车型的适配问题。
- 装在车机，不装在 iPhone。核心 CarPlay 不需要 ADB。

## 默认值调整

只影响全新安装、以及从没改过该项的设置；已有用户的配置不动。

| 项目 | 默认值 |
|---|---|
| 车机系统 | DiLink 3.0（首次引导与仪表卡判断） |
| 高级车辆数据 · 数据模式 | 旧版车机探测 · DiLink 3.0 |
| 车辆电量 / 隧道轮速 / 驻车播放视频 | 默认打开 |
| 充电接口 | 中国（GB/T） |
| 低电量提醒 | 25% |
| 导航「向 iPhone 报告位置」 | 默认打开 |
| 比亚迪导航「通话、Siri 与媒体按键」（实验性） | 默认打开 |
| 音乐缓冲 | 无线与 USB 均为 1000 ms（最稳定档） |
| 链接「打开 DiPlay 时连接」 | 默认打开 |
| 链接「自动开启热点」 | 默认打开 |
| 车机热点 | SSID `car` / 密码 `12341234` |
| 导航音频通道 | 14（BYD 导航语音在传统流 14；选 0 会被车机当成媒体） |
| 氛围灯 | 总开关与音乐律动打开；颜色随节拍、亮度过渡快速、亮度上限最大档、区域全部；跟随专辑封面取色 |

## 功能改动

1. **方向盘音量拨轮按键播放／暂停音乐**：按下方向盘音量拨轮即可控制 CarPlay 音乐的播放与暂停。
2. **应用图标更换**：改为 DC 字母组合图标（原为绿色 CarPlay 标记），与官方版共存时便于区分。
3. **返回键在 CarPlay 与 DiPlay 主页之间来回切换**：会话在后台运行时，主页返回键回到 CarPlay，而不是退出到车机桌面再重新打开。
4. **离开 CarPlay 不再拆连接**：切到其他车机应用或按返回回主页时会话保留，回来直接复用，不再每次重新握手黑屏 3–30 秒；只有主动点「断开」才拆会话。
5. **支持备份应用设置**：可导出设置备份，文件保存在 `Downloads/DiPlay/` 目录下。
